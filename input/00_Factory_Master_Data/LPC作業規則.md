# LPC 公司作業規則（給 FAU NPI 工具用）

> **這份是什麼：** 一位 LPC（Lumora Photonics）NPI 工程師平常就知道的公司規則。依 FAU 文件模擬產生器所用的公司層級設定整理（2026-11-01）。
>
> **用途：** 和 `內容深度規格.md` 一起交給 FAU NPI 工具，讓各站做得出完整、算得對的文件。
>
> **隔離：**
> - 這裡只有公司政策、費率、時程習慣和流程規則，沒有任何案例的數值、決定或答案。
> - 每個案例的實際情況（客戶的決定、已下的採購單、各版當時的庫存）要做成工具的輸入，不從這份推。
> - 寫成「範圍」的地方是經驗值。工具要選一個值，並在文件裡寫明依據。

## 2. 時程習慣（工作天）

初版：

| 事件 | 和前一個事件相隔 | 常見值 |
|---|---|---|
| 收到 draft spec → 回 DFM | 3–6 天 | 3 天 |
| DFM → 客戶同意 | 3–6 天 | 4 天 |
| 客戶同意 → 正式規格發行（規格書、圖面、BOM 同一天） | 2–7 天 | 5 天 |
| 規格發行 → 客戶接受 | 1–4 天 | 1 天 |
| 客戶接受 → 成本送財務 | 0–3 天 | 1 天 |
| 送財務 → 財務確認 | 1–3 天 | 1 天 |
| 財務確認 → 報價 | 1–3 天 | 1–2 天 |
| 報價 → 客戶 PO | 2–6 天 | 3 天 |
| 收到 PO → 備料通知 | 1–4 天 | 1 天 |
| 備料通知 → 採購下單 | 隔天 | 1 天 |

工程變更（ECR）：
- **流程：** 收到 ECR → 影響評估（2–3 天）→ 客戶核准 → 長交期料先行採購（核准後第一個工作天）→ 規格發行 → 成本 → 財務 → 報價 → PO 變更單 → 備料變更通知。
- **小改：** 沒有財務確認、報價和 PO。成本仍要送財務，規格發行和備料通知可以在同一天或隔天。
- **生產批：** 一批從開工到出貨約 2 週（含鍍膜外包的再加約 2 週）；空運到客戶 3–4 天。

## 3. 計價政策

- **單位成本**：依序加總
  1. 材料：BOM 展開用量 × 價格表依計價數量取的級距價
  2. 外包服務與每批收費，按每顆分攤
  3. 加工：（整備時間 ÷ 成本批量 + 單件時間）× 工作站費率
  4. 物料管理費：（材料 + 服務）× **3 %**
  5. 製造費用：加工 × **22 %**
  6. 報廢：以上合計 × 報廢率
  7. 管銷：製造成本 × **8 %**
- **報價**：成本 ÷（1 − **30 %** 目標毛利），無條件進位到 **USD 0.50**。
- **工作站費率**（USD／小時）：

  | 工作站 | 費率 | 工作站 | 費率 |
  |---|---|---|---|
  | FPR | 22 | CPM | 55 |
  | PMA | 40 | CON | 26 |
  | VGA | 24 | OPT | 48 |
  | CUR | 12 | PKG | 18 |
  | POL | 30 | REL | 15 |
  | EFI | 45 | FOA | 22 |
  | SCT | 28 | | |

  費率以主資料為準。
- **報廢率**（依產品類型的經驗值）：

  | 產品類型 | 報廢率 |
  |---|---|
  | 扇出線 | 5 % |
  | 一般光纖陣列（≤ 16 通道） | 8 % |
  | 32–48 通道陣列 | 10 % |
  | PM 陣列 | 12 % |
  | PM 陣列，端面在空氣中或有鍍膜 | 14 % |

  包材不算報廢。
- **成本批量**：取該案的典型生產批量。一般 500–1,500 顆，PM 陣列約 300 顆，鍍膜批次限 150 顆。
- **每批驗證**：光纖陣列每個生產批做一次批次驗證（服務代碼 SV-REL-LOT，主資料有價格），按批量分攤到每顆。扇出線不做。
- **外包服務**：抗反射鍍膜等按顆計價，價格取主資料的服務表。
- **一次性費用（NRE）**：治具、測試設定、首件檢驗、一次性設計驗證，逐項列出金額。工程變更另列 ECR NRE。
- **成本變更說明**：寫成「約 ± USD x per pc full cost」，x 是把該變更前後各算一次成本的差。成本沒有變化的寫「None」。

## 4. 標準製程（工序與工作站）

| 產品 | 工序順序（工作站） |
|---|---|
| 光纖陣列 | 光纖準備、排帶（FPR）→ V 槽組裝、上蓋板（VGA）→ 固化（CUR）→ 研磨（POL）→ 端面干涉量測（EFI）→ 芯位量測（CPM）→ 尾套（VGA）→ 接頭端接（MPO 用 CON，單芯用 SCT）→ 光學測試（OPT）→ 標籤、包裝（PKG）→ 批次驗證（REL，另計） |
| PM 陣列 | 在上列加：慢軸對位（PMA）、接頭鍵位對位（PMA）；有鍍膜時加預烤、外包鍍膜、進料檢驗 |
| 扇出線 | 主幹裁切與外被（FOA）→ 分支與分歧盒灌膠（FOA）→ MPO 端接（CON）→ LC 端接（SCT）→ 光學測試與極性檢查（OPT）→ 標籤、捲線、包裝（PKG） |

- 整備時間通常 10–30 分鐘／批。
- 單件時間依通道數、接頭數量而定，參考主資料和製程能力文件。

## 5. 商務規則

- **生效範圍：**
  - 變更從第一個材料還沒投入的批次開始。
  - 已投料或已開工的批次照原版做完。
  - 新料交期趕不上時，變更順延到下一批，或延後該批交期，並在影響評估信裡說明。
- **呆料：**
  - 因客戶變更而作廢的本案專用料，由客戶負擔。
  - 已到貨的作廢料按成本計。
  - 訂製料還在生產中而減單或取消時，收 **30 %** 取消費。
  - 一般標準料（工廠其他案子也用得到）回到庫存，不向客戶收費。
- **小改：** 不重新報價、PO 不改版，成本增加由 LPC 吸收。
- **大改：** 重新報價（報價單號加 `-R1`、`-R2`…），客戶發 PO 變更單（版次加 1）。
- **先行採購：** 交期長、會影響交期的料，在客戶核准 ECR 後第一個工作天先下單。
- **不准做的事：**
  - 不在玻璃上雷射刻字（用旗標標籤）。
  - 不在 2.0 mm 套管上噴印（用纏繞標籤）。
  - 標籤距尾套至少 30 mm。
- **一次性驗證：** 超出例行能力的可靠度要求，只做一次設計驗證、收 NRE；每批仍做例行的批次驗證。例如 2000 小時濕熱、1000 次溫度循環、−55 °C。

## 6. 備料規則

- **可用量：** 共用料的可用量 = 在庫 − 已分配。本案專用料（新料號）只有本案自己下的採購單。
- **需求：** 每批照該批版次的 BOM 計算，用量 ×（1 + 報廢率），包材不加。
- **下單：**
  - 數量取最小訂購量（MOQ）的倍數。
  - 採購日是備料通知的隔天，ETA = 採購日 + 價格表交期。
- **加量：** 未結單要加量時，另開一行，寫「原單號 (increase)」。
- **到貨判斷：** ETA 不晚於下次備料通知日的單，視為已到貨。
- **晚到：** 每個料的 ETA 晚於需要日（第一個缺料批的開工日）時，標出晚幾天，並在信裡說明影響哪一批、約幾顆。

## 7. 編號登記

- LPC 文件編號：

  | 文件 | 編號 |
  |---|---|
  | 規格書 | `LPC-PS-26案號` |
  | 圖面 | `LPC-DWG-26案號` |
  | BOM | `LPC-BOM-26案號` |
  | 單位成本 | `LPC-UC-26案號` |
  | 報價 | `LPC-Q-26-nnnn`（流水號） |
- LPC 採購單號：`PO-L26-nnnn`，一個號碼只用在一張採購單，不重複。
- **產品料號：** 每一版換一個字尾字母，小改也換，例如 `…-0F`、`-0G`、`-0H`。
- **共用登記表：** 工具要有一份已用編號的登記表（報價單號、採購單號、料號），產生新號碼前先查。
- **檔名：** 照參考文件的命名，日期用事件日期。例如：
  - `日期_DFM_Feedback_客戶規格號.eml`
  - `LPC-PS-26案號_Rev版次_Product_Specification.docx`

## 8. 範本

- 各類 LPC 文件的版面（字型、顏色、表頭、頁首頁尾、Excel 分頁結構）照開發案 097 的參考文件，做成範本檔。
- 版面放範本，資料放資料檔，不寫死在程式裡。
